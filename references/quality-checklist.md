# Quality Checklist

Run this before delivery.

## Required Content

- Title is present and readable.
- Portrait is present.
- Name is exact.
- Team is exact.
- Language matches request.
- Personal title `最佳____` is present.
- Achievement congratulation or target-hit copy is present.
- Month/theme is present or represented.
- Toki appears if requested or part of the current campaign style.

## Visual Checks

- Final size is `3508 x 4961`.
- Portrait head is not cropped.
- Face is centered enough for the frame.
- Person and generated frame are aligned.
- Text is not tiny, crowded, or overlapping.
- Chinese/English line breaks look intentional.
- Art typography does not contain wrong characters.
- Toki proportions are short, chubby, pear-shaped.
- Same-month unified layout is preserved when requested.

## Failure Response

If any check fails, revise before showing the user. Do not present a flawed image as final with apologies.
